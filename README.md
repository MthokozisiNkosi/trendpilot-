# TrendPilot

TrendPilot is a trend-driven YouTube Shorts production and publishing platform.

## Launch configuration
- One English-language YouTube channel
- Two Shorts per day
- Dynamic trend discovery rather than a fixed niche
- South Africa-aware trend discovery, with globally relevant English-language topics
- Human approval required before publishing during initial launch
- Default timezone: Africa/Johannesburg

## Production pipeline
1. Discover and score current trends
2. Research and verify factual claims
3. Draft short-form scripts and hooks
4. Generate narration and source/licensed visuals
5. Assemble vertical videos with captions
6. Queue for human review and approval
7. Upload and schedule approved videos to YouTube
8. Track analytics and optimise future topic selection

## Planned stack
- Next.js dashboard
- Supabase database and storage
- Vercel hosting
- YouTube Data API for publishing

## Security
Never commit API keys, OAuth refresh tokens, service-role keys, or other secrets. Store credentials in environment variables and server-side secret storage.
